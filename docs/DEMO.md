# Demo script (under 3 minutes)

Setup: `node scripts/make-fixtures.mjs`, open OUIJA, **Settings → Add folder →** `fixtures/chaos/`, wait for indexing to finish.

1. **(0:00) Hook.** "We all have files we can't find." Show the messy folder in the file manager.
2. **(0:15) Search by meaning.** Ask: *where is the poem for Rosa?* Result: the 2019 document and its **2008 draft, inside a backup**, marked "Resurrected".
3. **(0:50) Resurrection.** Ask: *thesis acknowledgements to Rosa Campos*. The WordPerfect file no program can open is rescued from its raw bytes, with medium confidence. Open "Export".
4. **(1:15) Every file type.** *where is the haka lens logo* (an image) and *camila's audio files* (audio only).
5. **(1:35) Ghosts.** Ghosts tab: the obituary of the thesis draft.
6. **(2:00) People.** People tab: Rosa's timeline (2008, 2011, 2019). Merge "Rosita" with "Rosa".
7. **(2:15) Gallows.** Gallows tab: what is in the trash. Mark a file, go to Resurrection and bring it back.
8. **(2:30) Privacy.** Settings: "Everything local". Show there is no internet connection (airplane mode).
9. **(2:45) Close.** Minimize to the taskbar and reopen with the shortcut.
